# Perpetuity About + Team Page

## Goal
Create a combined About and Team page that feels native to Perpetuity: warm ivory business-card texture, precise glass layers, metallic type, quiet blue highlights, and restrained motion.

## Page structure
- Open with a full-width editorial statement about Perpetuity as an always-on intelligence team, using only existing product language.
- Explain the operating model through three concise bands: connect the company’s world, keep intelligence active, and turn signals into approved action.
- Add an “operating principles” section focused on context, judgment, permission, and continuity.
- Introduce a compact team section with clearly presented fictional placeholder people, roles, short bios, and generated abstract portraits until real details replace them.
- Finish with a restrained contact action using the existing `hello@perpetuity.works` address.

## Navigation and metadata
- Add a dedicated `/about` page with unique title, description, Open Graph metadata, and Twitter card metadata.
- Point the existing landing-page About link to `/about` rather than the current in-page placeholder.
- Keep About outside the operational app sidebar unless it already has a suitable public navigation location.

## Visual direction
- Preserve the project’s warm ivory and metallic glass system rather than introducing a new palette.
- Use the dashboard sans typography for interface text and restrained editorial serif moments for key statements.
- Avoid a generic startup team-card grid: use an editorial roster with compact glass profile windows and asymmetrical rhythm.
- Keep animation limited to soft reveal, light movement, and subtle portrait depth; honor reduced-motion settings.

## Technical details
- Build the page as a TanStack route and reuse the existing global tokens and shared controls.
- Add only the page-specific visual tokens needed for portraits and composition.
- Verify the new route, landing-page link, desktop layout, mobile layout, and current build health.
